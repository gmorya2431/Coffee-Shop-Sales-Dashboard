# ☕ Coffee Shop Sales Analysis & Dashboard

## Project Overview
An Excel-based data analytics project designed to analyze coffee shop sales, identify trends, and present business insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Slicers and filters
- Data visualization

## Key Performance Indicators (KPIs)
- **Total Revenue:** $698,812.33
- **Total Transactions:** 149,116
- **Total Quantity Sold:** 214,470
- **Average Order Value:** $4.69
- **Average Unit Price:** $3.38

## Dashboard Features
- Monthly sales analysis
- Store location performance
- Product category and product type analysis
- Sales trends by day and hour
- Interactive filtering for data exploration

## Dataset
The dataset contains transaction IDs, dates, times, quantities, store locations, product categories, product types, and unit prices.

## Project Objectives
- Analyze sales performance and trends.
- Identify top-performing products and locations.
- Understand purchasing patterns.
- Support data-driven business decisions.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the available filters and slicers to explore the data.
